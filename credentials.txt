Instrucciones para crear el usuario manager en la BD:

Si el usuario manager no existe en la base de datos, ejecuta:

INSERT INTO role (name) VALUES ('ROLE_MANAGER');

INSERT INTO user (username, password) VALUES ('manager', '$2a$10$YOUR_BCRYPT_HASH');

INSERT INTO user_roles (user_id, role_id) VALUES ((SELECT id FROM user WHERE username='manager'), (SELECT id FROM role WHERE name='ROLE_MANAGER'));

NOTA: Las passwords se almacenan encriptadas con BCryptPasswordEncoder.
Para generar un hash bcrypt, usa: java -jar lombok.jar o cualquier generador online.
